# Isolated validation set v1 (archived 2026-09-28)

847 validation windows (42 positive). Archived deliberately, not because of an error:
Manual-BG-RPI14..19 (new real RPI negative recordings) were integrated and the split
extension (append-only; no earlier recording moved) assigned Manual-BG-RPI16 to
validation, adding 166 real-device negative windows. The normalization statistics
were also recomputed for the new training windows. v2 is frozen on the next
evaluation run. Metrics computed on v1 and v2 are not directly comparable.
